## Deliberate scope choices

The default-variety catalogue remains a single approximately 950 kB uncompressed JSON file, with family files loaded separately. The historical [split-index evaluation](catalogue-evaluation.md) saves 40.8% of gzip catalogue bytes but reduces offline coverage. The subsequent [lossless application evaluation](compact-application-evaluation.md) retains every field, preserves complete default-variety offline coverage and reduces measured cold application transfer by 10.1%. It is implemented as an opt-in compact production build; standard builds retain their existing default.

Evolution condition alternatives are expandable to keep long game-specific requirements readable without overwhelming the tree. `is_default` is upstream metadata and is omitted from condition text; game/version-group and form requirements remain visible in the alternatives.

The optional server API now returns normalized family trees, matching the static client model. External consumers of the old raw upstream family response would need to adapt. The application itself uses saved files throughout.
